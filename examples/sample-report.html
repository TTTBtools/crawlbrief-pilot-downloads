Scope and limits

This report uses imported crawl data, not a new live-site test. Supported checks: HTTP errors, missing responses, redirects, exported noindex, and empty HTML title, meta description or first H1. Missing metadata is checked only on successful HTML rows.

Redirects, noindex and metadata require human judgment. Performance, accessibility compliance, security, rankings, conversion impact, crawl completeness and redirect destinations are not verified. URL parameters remain in the report; the reviewer must remove sensitive details before sharing.

The exporter confirmed review of this report. Confirmation is a workflow step, not an independent certification.
